# Quiz

Twenty clinical scenarios, about 25 minutes. Each question has one best answer; check it to see the explanation. When you have checked all twenty, a table shows your results across five topics: data leakage, choosing a method, clinical application, medical imaging and temporal data.

Nothing is stored or sent anywhere. Reloading the page starts again.
